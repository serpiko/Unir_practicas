 Dart for Flutter — Learning Path
  
  1. Language Basics

  - Variables & types (var, int, String, double, bool, dynamic)
  - Null safety (?, !, ??, ??=)
  - Control flow (if/else, for, while, switch)
  - Functions (positional, named, optional params, arrow =>)

  2. Object-Oriented Dart

  - Classes, constructors (default, named, factory)
  - final vs const
  - Inheritance & interfaces (extends, implements, mixins)
  - Getters & setters

  3. Collections

  - List, Map, Set
  - Spread operator ...
  - Collection if and for (used heavily in Flutter widget trees)

  4. Async Dart (critical for Flutter)

  - Future and async/await
  - Stream basics
  - try/catch with async

  5. Dart Patterns used in Flutter

  - Named constructors
  - @override
  - Enums
  - Generics basics (Widget<T>)
